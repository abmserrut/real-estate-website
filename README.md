# 🏠 Real Estate Website

Responsive real estate website developed as part of a web development training project.

---

## 📖 Overview

This project showcases a modern real estate website featuring:

- Property listings
- Blog articles
- Contact forms
- Responsive layouts

The main objective of this project was to strengthen front-end development skills while applying modern web development practices using:

- HTML5
- CSS3
- JavaScript
- Sass (SCSS)
- Gulp

---

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Sass (SCSS)
- Gulp
- Responsive Web Design

---

## ✨ Features

- Responsive design for desktop, tablet and mobile devices
- Property listing pages
- Blog section
- Contact page
- Optimized images (JPG and WebP)
- Dark mode support
- Modern UI design
